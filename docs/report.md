# 账户行动报告契约

当前入口使用 `report/templates/account_report.html`，页面标题为“账户行动报告”。布局为3个锚点，移动端单列：

1. 账户总览：真实账户总资产、已核验可用现金、当前持仓数量→4只目标、过渡持仓数量、账户方向与三项待办、成长价值组内进度。
2. 现有持仓管理：优先显示非目标真实持仓的持有、反弹分批卖出、条件回补与最终盈利退出计划；页面成本参考和清仓回本价分列，不能只有等待清仓。
3. 目标组合与资金承接：按510500、159141、159259、159263固定角色排序，显示最终方向、已有目标持仓操作及价格/可用资金双条件。无即时配置或清完全部旧仓的要求。

不再有自选池/T网格页面或结果，也不把趋势榜、盈亏榜、风险榜拆成多个主导航。旧决策展示辅助函数已移除；历史模板不属于当前渲染入口。

持仓为0或空缺时不伪造持仓；实际可用现金未采得不能由“资产−市值”推断。组内40/60明确不是全账户配置。组内空仓不计算百分比；预算未定不显示建仓完成百分比。

价格显示为参考价，候选数量显示为「建议份额」，集中说明执行前按实际资金、可卖份额和累计占用调整，不逐项重复「待核验」。不宣称已下单、已改真实网格或一定触发。退出利润不能直接作为买入可用资金。AI不出现在首页制造另一套操作口径。

资金说明遵循 `LEGACY_RECOVERY_FIRST`：现有资金先用于待退出 ETF 的回本管理，目标组合仅使用扣除旧仓回补和周转预留后确认剩余的可用资金。报告应区别现金余额和实际可用资金；数据缺口逐项指出来源与影响，不将未持仓、已停用或非法数量混写为「待核验」。
