## 决策顺序

1. 校验真实采集和行情完整性，识别既定账户角色。
2. 计算量价指标和短期趋势，保留流动性、K线完整性、涨跌幅和组合仓位硬过滤。
3. 优先为现有持仓生成持有、反弹部分卖出、条件回补和最终退出计划，清仓核验缺口不消除过渡期建议。目标组合另加价格与可用资金双条件，允许价格合适时使用现有可用现金，否则等待旧仓回款。高风险暂停新增投入，目标仓位为0；不机械亏损清仓。
4. 成长／价值只计算组内40/60进度；建仓期优先满足回落条件的低配侧，不强卖高配侧。
5. 网格分别计算两侧幅度与数量候选，区分资金与库存核验状态。
6. 清仓核验本轮净投入；AI与HTML使用同一结构化决策。

`159141`按行业主题处理，不因名称含“科创”被误归普通宽基。趋势分不自动选新标的、不单独决定全账户资金分配。现有80%总仓位保护仍保留；持仓市值占比不能充当总资产仓位。
