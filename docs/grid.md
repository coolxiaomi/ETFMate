# 低频非对称条件计划

指定目标的波动交易以隔日或每周数次为频率目标；不保证频率。原自选池T网格候选模块已退出当前流程。

## 参数候选

ATR使用本次行情的ATR14百分比。下列系数为起始启发式，未经收益最优性或触发频率回测，不当作用户确认的固定参数。

| 角色 | 买入下跌百分比 | 卖出上涨百分比 |
| --- | --- | --- |
| 510500低频波动 | max(2,1.4×ATR) | max(1.5,1.2×ATR) |
| 赛道与成长价值建仓 | max(3,1.8×ATR) | max(1.5,0.9×ATR) |

买入反弹为clamp(0.15×ATR,0.15,0.8)，卖出回落为clamp(0.10×ATR,0.10,0.6)，单位均为%。两者独立，不再强制相等。

保留有效现有基准价，无基准时用现价作参考；偏离现价超过两倍最大触发间距标记待复核，不自动重置。首笔买入示例为基准×(1−下跌%)×(1+反弹%)，卖出示例为基准×(1+上涨%)×(1−回落%)，不等同于路径依赖条件单的保证成交价。

## 数量与资金

候选数量优先读取Touker真实两侧数量，缺侧数量才回退共用数量；不把底仓或持仓上限当单笔数量。卖出候选取整至100份且不穿透候选底仓。底仓候选为至少一半现有持仓向上取整至100份，并尊重更高的原底仓；小仓位不输出卖出候选。

逐步建仓时买入候选数量至少为卖出候选的2倍，这是待预算核验的起始方案，不保证净买入。没实际数量证据时不凭空填1000份。所有买入建议仍需满足全账户预算、现金、冻结和网格累计占用约束；仅在已设置最大持仓时应用该固定上限。

`candidate_buy_quantity/candidate_sell_quantity`是候选；`suggested_buy_quantity/suggested_sell_quantity`为已核验执行数量，当前统一资金与可卖量尚未完成核验，执行数量留空且`grid_applicable=false`。报告统一展示为「建议份额」，执行边界集中说明，不逐格追加「待核验」，也不显示0份条件单。风险或80%总仓位限制时停用买入侧。

## 清仓保护

普通部分卖出允许低于成本，已亏损目标不因此自动暂停所有波动卖出。循环卖出必须由平台最低底仓保护；无法保证时停用。每次成交后更新本轮净投入，最终清仓按[sell-policy.md](sell-policy.md)单独核验。非目标持仓仍给出过渡期部分卖出及先卖后买的条件回补计划；回补不自动扩大旧仓，不与目标建仓重复占用回款。

报告仅提供修改建议，不自动操作Touker。

## 现有待退出持仓

现有非目标仓同样生成ATR波动幅度、反弹分批卖出价和候选数量，不能提前return只给清仓提示。新过渡计划以当前价为候选基准，调整实际旧网格需另核验。卖出数量优先沿用原网格数量，缺失时按实际持仓约1/4取整，候选最低库存至少100份，并尊重更高的已设底仓，避免自动清仓。

正常行情下可给出先卖后买的回补方案：候选回补为卖出候选的一半向下取整至100份，待实际卖出、资金分配及仓位核验。回补金额不超过分配给它的实际可用回款，份额不超过实际已卖量，不扩大旧仓；风险高时暂停回补，仍保留反弹卖出计划。上述比例是分析起始候选，不是用户固定参数或盈利承诺。

建议先管理现有仓，再将释放的资金转给目标；旧仓退出与目标建仓不是立即一次完成的切换。

## 可选底仓上下限（2026-09-08 用户确认）

未设置最小底仓或最大持仓表示不设对应固定限制，不代表漏配、必须核验或无限可用资金。模型字段仍为 `None`，不以 0 替代；显式 0 是已配置数值。报告分开展示当前设置与策略建议。`current_min_base_quantity/current_max_position_quantity` 保留平台值，`min_base_status/max_position_status` 区分 `UNSET/CONFIGURED`。

本次保留量继续沿用角色策略：目标仓建议保留至少一半库存，旧仓分批退出建议保留至少100份，随持仓变化重新计算；它是可调整建议，不冒充用户固定下限。显式更高底仓同时约束目标仓与旧仓卖出。最大持仓未设时不增加固定上限；已设时买入建议按剩余额度向下取整至100份，旧仓回补按建议卖出后的额度计算，并须在实际成交后重算。

本次没有引入自动预算分配或自动调整平台设置。80%组合保护上限、可用资金与可卖量、累计占用及最终清仓不亏约束继续适用。ATR决定价格间距；未设置单笔数量时仍应说明来源缺失，不能从「不限」推导出任意份额。
