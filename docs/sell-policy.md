# 清仓不亏规则

2026-09-07更新：允许浮亏，允许低于成本的部分卖出；最终清仓必须不亏本金。费用继续忽略。此规则替代旧的每笔卖出成本底线。

## 本金口径

本轮从空仓开始，剩余净投入 = 累计买入金额 − 已成交卖出回款 − 已收到现金分红。拆分/合并份额须同步调整库存。最终清仓回本价 = max(0,剩余净投入 / 剩余数量)。这不是整个账户跨标的盈亏互抵，也不是只看最后一笔交易。

示例：买入1000份、单价1元；先以0.8元卖出200份，剩余净投入840元、库存800份，最终回本价1.05元。以1元卖掉剩余800份仍会累计亏40元，必须阻断。

`Position.net_invested_amount`和`cost_basis_verified`表示已核验的剩余净投入；它必须来自本轮完整资金与库存证据，不能由普通`cost_price`或页面浮盈比例推断。当前真实采集器尚不证明此口径，不自动将字段设为已核验。因此普通成本只能作为参考，最终清仓默认等待核验。不得手工补造该字段生成正式建议。

## 数量与状态

- 提议数量必须大于0且不超过持仓；缺数量按清仓处理，不能默认当成部分卖出。
- `PARTIAL_ALLOWED`：数量小于库存，允许低于成本；成交后更新剩余净投入，不能将旧快照重复用于后续卖出。
- `PENDING_COST_BASIS`：清仓所需净投入未核验，即使页面浮盈也不能宣称清仓已获准。
- `BLOCKED_LIQUIDATION_LOSS`：清仓所得不足回收净投入，等待回本条件。
- `LIQUIDATION_CONDITIONAL`：参考价满足条件，执行前还须复核净投入、实际可卖量、有效限价及交易限制；不保证成交。
- 非有限价格、数量及超卖进入`PENDING_VERIFICATION`。

部分卖出的允许仅指符合用户的盈亏约束，不等于可卖库存已核验或已授权下单。网格必须通过最低底仓防止连续触发清空库存；最后一笔转为单独清仓核验。平台无法保证库存保护时停用整个网格，部分卖出另行安排。

趋势转弱、期限到达、再平衡、仓位超限均不能绕过清仓不亏原则，也不能据此自动加仓摊低成本。

部分卖出评估附带projected_remaining_quantity、projected_remaining_net_investment和projected_liquidation_floor，仅表示按参考价成交后的推演；只有真实成交确认后才可更新正式账目。
