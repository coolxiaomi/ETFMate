# 账户角色与动作契约

当前契约为 `etf_account_transition_v4`，账户模式为`ROLE_BASED_ACCUMULATION`。角色先于趋势评分决定方向；技术评分与硬过滤只影响风险和是否暂停新增投入。

| 角色/情形 | 动作状态 | 执行含义 |
| --- | --- | --- |
| 目标等待回落 | WAIT_DIP | 低频波动或逐步建仓，不立即买入 |
| 风险或仓位限制 | WAIT_BUY_REVIEW | 暂停新增投入，保留风险提示 |
| 组内高配侧 | WAIT_PAIR_BALANCE | 暂缓新增，等待低配侧回落，不强制卖出 |
| 现有待退出持仓 | MANAGE_EXISTING | 持有、反弹分批回收、受控回补及最终退出，清仓核验单独处理 |
| 清仓参考条件满足 | LIQUIDATE_CONDITIONAL | 仅清仓候选，执行前复核限价和库存 |
| 无持仓旧网格 | RETIRE_GRID | 停用该标的买入计划，不复活为建仓候选 |

159781不是最终波动配置目标，但现有持仓仍接受波动改善与逐步退出建议。受控回补需要真实卖出回款，不自动扩大旧仓；弱趋势不能导致自动亏损清仓。高风险保留风险目标仓位0，建议执行后仓位仍为当前仓位，调整量0，避免把期望与未执行计划混用。

全账户角色预算未知时`target_position_ratio`为空，不把组内40/60写成全账户仓位。`action_quantity`留空；`candidate_liquidation_quantity`只在清仓参考条件成立时给出。网格候选数量与执行数量分别记录。

资金仓位口径降级为持仓市值占比时，不冒充账户总资产仓位触发硬上限。可用现金、冻结和条件单占用未核验时不直接安排新增资金。

资金优先级为 `LEGACY_RECOVERY_FIRST`：先安排待退出 ETF 的回本管理资金，目标组合仅使用 `VERIFIED_SURPLUS_AFTER_LEGACY_RESERVE`。`allow_existing_cash=true` 表示可使用满足优先安排后的现有余款，不代表可以抢占旧仓资金。资金优先级不改变价格、风险、仓位或清仓约束。
