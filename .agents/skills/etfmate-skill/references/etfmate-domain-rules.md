# ETFMate 运行检查清单

## 采集与范围

- 真实登录态经web-access采集同花顺资产、持仓、备注、清仓和5个交易范围；滚动到底，保存累积证据。
- Touker保留全部条件单按页面数量对账，真实网格参与参数分析，非网格记录忽略数量。
- 不访问原自选池，不运行独立T网格。研究范围只包含当前真实持仓、真实网格及510500、159141、159259、159263。
- 验证码、风控、协议或漏采时停止。data_quality必须PASS，样例不能生成正式建议。

## 角色与决策

- 510500低频赚波动，159141赛道低吸；159259成长40%、159263价值60%只指组内市值。
- 当前逐步建仓，不一次性买满，不机械卖出高配侧凑比例；159781等旧仓持续提供波动改善与分批退出建议，最终清仓不亏。
- 允许浮亏与低于成本的部分卖出。清仓核验完整持仓周期净投入，普通页面成本不足以证明。
- 网格幅度和数量两侧独立，连续卖出不能突破底仓；缺资金或可卖量时仍给条件建议，执行数量留空。未设置最小底仓或最大持仓表示不设固定限制，不是数据缺口；可单独给出随持仓和行情复评的保留量建议。已设置上下限继续遵守。
- 未成交回款不算可用资金。80%保护上限及高风险不能被网格绕过；组内比例不能充当全账户预算。
- 现有资金先满足待退出ETF的回本管理与合理周转预留，目标组合只用其后确认剩余的可用资金；不以此优先级自动扩大旧仓或承诺回本。

## AI与报告

分析与AI契约均为etf_account_transition_v10；先analyze，再宿主AI复核和ai-attach，最后report。旧契约重新生成，不能改版本冒充新分析。

报告为账户总览、现有持仓管理、目标组合与资金承接；指标与依据折叠，候选与执行条件区分。实时运行默认用ShareOne发布，用户明确不发布时不发布；讨论和代码修改不自动启动实时采集。

- v7：账户限制仅总览展示；逐只区分建仓与已有仓位管理，MIXED只作条件观察、不单独硬阻断，实际资金和库存限制继续生效。

- v8：完整日技术指标与实时报价分开，精确OHLCV与真实成交额逐日对账。当前部分退出独立于未来上涨网格；正文先给本次动作，双向草案折叠。全部监控条件单纳入执行冲突核对。AI需绑定本轮run_id/review_id/input_fingerprint并逐只PASS，未解决冲突阻断正式report，原文不再被清仓提示覆盖。

- v9：按已确认封闭资金池、无手动委托、成交自动同步事实计算现金与可卖量；T+1减当日累计买入，T+0使用当前持仓，卖出不重复扣减。全部条件单共用现金，不把监控当冻结；当前退出用价格条件卖出，未来路径用独立回落卖出，先处理重叠原单。公式与来源见docs/investment-plan.md、trading-eligibility.md、conditional-order-execution.md。

- v10：理论确认边界与首个满足条件的报价档位分开，反弹向上取档、回落向下取档。质量闸门重算decision_review与action_plans；AI核对数量来源、减持比例、未触发后的复评及委托后续处置。80%仅限制新增买入，未定风险/预算/期限不补造；回本清仓可能长期不能完成，费用忽略及策略效果未验证须明确。历史失败按真实原文归类，不等于亏损率；当前成交情景不能与未来反弹单回款混用。
